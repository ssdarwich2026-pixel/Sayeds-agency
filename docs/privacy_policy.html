Privacy Policy — Current Bureau Uploader

Effective date: October 18, 2026
Operator: Current Bureau (channel owner, thedayfilenews@gmail.com)

What this application is

Current Bureau Uploader is a private, single-user automation tool operated by the owner of the YouTube channel Current Bureau. It is not a public service and it has no users other than the channel owner. Its only function is to upload the owner's own original videos, together with their titles, descriptions, tags and thumbnails, to the owner's own YouTube channel through the official YouTube Data API v3.

Data the application accesses

With the channel owner's authorization (Google OAuth 2.0, scopes youtube.upload and youtube), the application accesses only the owner's own YouTube account, and only to perform the upload and channel-management actions the owner has instructed. The application does not collect, read, or store personal data about any other person, and it does not access viewers', subscribers', or commenters' personal information.

Data the application stores

  • OAuth tokens. The access and refresh tokens issued by Google are stored in a single file (token.json) on the owner's own server, protected with restrictive file permissions (owner read/write only). Tokens are never transmitted to any party other than Google's own API endpoints.
  • Upload records. A local log of the owner's own uploads (video ID, timestamp, source file path, privacy setting) is kept on the same server solely so the same file is never uploaded twice.
  • Video files and metadata. The videos, titles, descriptions and thumbnails the application uploads are the owner's own content, already stored on the owner's server.

Data sharing

No data is sold, rented, shared with, or disclosed to any third party. The application communicates only with Google's YouTube API endpoints to carry out the owner's uploads. It contains no advertising, analytics, or tracking components.

Data retention and deletion

OAuth tokens and upload records are retained only while the owner uses the tool. Deleting token.json from the server immediately ends the application's access; the owner can also revoke access at any time from Google Account permissions. Revocation and deletion requests sent to the contact address below are honored promptly.

Security

Tokens are held on the owner's private server with owner-only file permissions and are never printed, logged, or included in any report or publication.

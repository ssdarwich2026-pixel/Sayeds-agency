# Foxwatch Style Bible (observed from the 53-piece collection)

Written from direct observation of the artwork, not from descriptions.
Every new piece must read as "same family" at thumbnail size.

## The visual DNA

- **Subject:** anthropomorphic fox, upper-body portrait, 3/4 or profile view.
  Character fills the frame. Never full-body, never landscape.
- **Rendering:** faceted low-poly / geometric shading. Flat angular planes with
  visible facet edges. NOT smooth gradients, NOT photoreal, NOT anime-clean.
- **Background:** warm solid or near-solid wash — peach, salmon, amber, ember
  ("Ember Peach", "Amber Glow"). One tone, no scenery.
- **Palette:** earthy base (browns, tans, rust, cream) + jewel-tone accents
  (teal, deep blue, gold). Accents mark the archetype, never the whole piece.
- **Theme:** one occupation/archetype per fox + 1–2 props that say the job
  (archivist + books, striker + ball + numbered jersey). The prop is the story.
- **Line work:** dark angular contour strokes on key edges (jaw, ears, shoulders).
- **Format:** 512×512 PNG.

## Naming

`The {Title} — Foxwatch {Role}` — e.g. "The Archivist — Foxwatch Keeper".
Title and Role must both be new to the collection (roster-checked).

## Traits (schema)

Core five on every piece: **Background / Outfit / Expression / Activity / Mood**.
Optionals as observed: Accessory, Companion, Distinction, Marking, Eyewear, Gear.
Values stay in the established vocabulary (see metadata); new values only when
the art genuinely shows something new.

## Anti-patterns (reject)

- Photoreal fur, smooth airbrush gradients, anime faces.
- Busy backgrounds, scenery, text/words in the image.
- Second character or full body.
- An archetype already in the roster (no two blacksmiths).
